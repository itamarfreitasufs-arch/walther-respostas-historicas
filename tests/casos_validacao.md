# Casos de validação de mesa (fictícios)

Os resultados esperados são critérios para avaliação posterior, não demonstração de desempenho automatizado.

| ID | Input | Saída esperada |
|---|---|---|
| V01 | Q + título `Resultados` + descrição de três achados | Mapa + função Resultados; congruência com título |
| V02 | Q + título `Resultados` + fechamento que sintetiza e recomenda | Contraste entre título e função conclusiva/reflexiva, com justificativa |
| V03 | Q + texto, **sem título informado** | Pedir apenas o título da seção; não emitir parecer final |
| V04 | Q + declaração `seção sem título` + texto | Classificar função efetiva; título ausente declarado |
| V05 | Q + título `Considerações finais` + texto misto | Explicitar coexistência de resultados, inferência e reflexão, sem presumir defeito |
| V06 | Texto `ocorreram P e Q` | CONJ sem inferir P causa Q |
| V07 | Texto `P ou Q` sem exclusividade | DIS com exclusividade indeterminada |
| V08 | Texto `(P e Q) condicionaram R` | Estrutura composta e exame separado de relação causal |
| V09 | Seção bem construída | Até três pontos fortes; nenhuma fragilidade artificial |
| V10 | Pedido `aprendizagem ativa` | Uma pergunta formativa, aguardar réplica |

**Critérios verificáveis no arquivo:** presença de regra de título, limite de 360 palavras, 3+3 critérios, mapa antes do parecer, relatório sob demanda, preservação de evidências e incertezas.
